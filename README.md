# Paper Diver

O Paper Diver cria um índice das peças dos seus autos. No Codex ou no Claude Code, você pode perguntar sobre um PDF e abrir a página citada na resposta.

O piloto requer Windows x64 e uma conta convidada. [Tutorial de instalação](https://paper-diver-staging.kevinheck941972.workers.dev/#como-funciona)

| Assistente | Adicionar o catálogo | Instalar |
| --- | --- | --- |
| Codex | `codex plugin marketplace add kevinheck6/paper-diver-plugins` | `codex plugin add paper-diver@paper-diver` |
| Claude Code | `/plugin marketplace add kevinheck6/paper-diver-plugins` | `/plugin install paper-diver@paper-diver` |

Em uma nova conversa, peça **Conectar minha conta do Paper Diver**. Confira o código no portal e autorize o computador. Depois, peça **Adicionar um PDF à minha biblioteca**. Quando o índice estiver pronto, faça sua pergunta e peça a página que sustenta a resposta.

Os PDFs escolhidos ficam na biblioteca do escritório. Os dois assistentes compartilham a conexão no mesmo perfil do Windows.

Em [Minha conta](https://paper-diver-staging.kevinheck941972.workers.dev/conta/), **Desconectar todos os assistentes do escritório** encerra o acesso em todos os computadores vinculados. Para voltar a usar o plugin, autorize o computador novamente.
